Connect Google Calendar (one-time)
  1. Serve this folder over HTTP — Google Sign-In will not run from a file:// page. From this folder: python3 -m http.server 8787, then open http://localhost:8787.
  2. In Google Cloud Console, create a project and enable the Google Calendar API.
  3. Configure the OAuth consent screen (External is fine). Add your own Google account as a test user.
  4. Create an OAuth client ID, type Web application. Under Authorized JavaScript origins add http://localhost:8787 and http://127.0.0.1:8787.
  5. Paste the client ID below and sign in. It stays in this browser; it is not committed.
